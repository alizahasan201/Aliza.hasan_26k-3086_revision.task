# C Programming — PF Lab Tasks

Beginner-level C programs covering basic decision-making and scenario-based problems.

## Topics Covered

* `printf()` and `scanf()`
* Variables & Data Types
* Arithmetic Operators
* Relational & Logical Operators
* `if-else`
* `else-if`
* Nested `if-else`
* `switch`
* Nested `switch`
* Basic Percentage Calculations
* Input Validation

## Questions / Tasks

1. **Taxi Fare Calculator**

   * Distance-based fare
   * Night surcharge

2. **Grocery Store Discount**

   * Bill amount
   * Membership-based discount

3. **Grade Calculator**

   * Marks validation
   * Grade using `if-else`

4. **Mobile Load Bonus**

   * Network selection
   * Weekend bonus

5. **Library Fine Calculator**

   * Book types
   * Fine calculation
   * Priority member discount

6. **Cricket Team Selector**

   * Batting average
   * Matches played
   * Fitness status
   * Experience quota

7. **Meal Billing System**

   * Meal category using `switch`
   * Service charge
   * Customer discount using nested `if-else`

## Concepts Used

```text
Input → Conditions → Calculation → Output
```

All programs are written at a **beginner level** using the concepts learned in Programming Fundamentals.
